# UI 边距规范

4px 基准。所有面板的"行"（顶栏、侧栏头部、工具行、标题行、状态栏）共用同一套留白与图标按钮尺寸，
避免同一列里各行左边缘错位、图标贴边。

## 1. 水平留白（gutter）

| 断点 | 值 | 来源 |
|---|---|---|
| < 768px | 12px | `--app-gutter`（`src/index.css`） |
| ≥ 768px | 16px | 同上 |

用法二选一，**不要同时写**：

- 普通行：`px-[var(--app-gutter)]`
- 需要避开刘海/手势条的行（顶栏、编辑器工具行、底部状态栏）：加 `safe-x`，留白由它注入

> ⚠️ `safe-x` / `safe-top` / `safe-bottom` 定义在 `src/index.css`，加载顺序在 Tailwind 之后，
> 会**覆盖**同行元素上的 `px-*` 工具类。历史事故：顶栏写了 `px-3 md:px-4` 但实际计算值是 0，
> Logo 直接贴到窗口左边缘。所以带 `safe-x` 的元素一律不要再写 `px-*`。

## 2. 图标按钮

| 档位 | 命中区 | 写法 | 用在哪 |
|---|---|---|---|
| 常规 | 34px | `p-2` + 18px 图标 | 顶栏、页面级操作 |
| 紧凑 | 27px | `p-1.5` + 15px 图标 | 侧栏头部行、编辑器标题行 |
| 微型 | 22px | `p-1` + 14px 图标 | 列表项内联操作、筛选 chips |

- 同一行只用一档，不要 15px 与 18px 混排。
- 图标可见边缘到容器边缘 = gutter + 按钮内距，**不小于 20px**。
- 裸图（如 `Logo`）没有按钮内距，需自己补 `pl-2`，才能和右侧 `p-2` 图标按钮视觉对齐。
- 不要用负外边距（`-ml-1` 之类）去抵消留白。

## 3. 垂直与分组

| 位置 | 值 |
|---|---|
| 顶栏高度 | `min-h-14`（56px，配合 `safe-top` 撑高） |
| 头部行上下留白 | `py-3`（12px） |
| 工具行 / 状态行 | `py-1.5`（6px） |
| 同组图标间距 | `gap-1` ~ `gap-1.5`（4–6px） |
| 不同功能组之间 | `gap-2` ~ `gap-3`（8–12px） |
| 卡片内边距 | `p-5`（20px），圆角 `rounded-xl` |
| 页面级内容区 | `p-4 md:p-6` |

| 位置 | 文件 |
|---|---|
| 顶栏 + Logo | `src/components/AppLayout.tsx` |
| 侧栏头部行 / 搜索与筛选行 | `src/components/note/NoteListPanel.tsx` |

新增行时：先套 `px-[var(--app-gutter)]`（或 `safe-x`），再按第 2 节选图标档位。
