# 笔记原格式批量导出

## 背景与目标

当前单篇导出（`frontend/src/utils/noteExport.ts`）仅支持 PDF/DOCX 等转换格式，且思维导图/流程图依赖 DOM/iframe，无法批量处理。

本方案实现：

- **范围**：全部笔记（不含回收站，忽略当前筛选）
- **格式**：按存储原格式导出
- **结构**：保留应用内文件夹层级
- **输出**：优先 File System Access API 写入用户所选目录；不可行时 ZIP 下载到浏览器默认 Downloads

## 原格式映射

| note_type | 导出扩展名 | 文件内容 |
|-----------|-----------|----------|
| `markdown` | `.md` | `content.text` |
| `rich_text` | `.json` | BlockNote JSON |
| `mindmap` | `.json` | SimpleMindMap JSON |
| `flowchart` | `.drawio` | Draw.io XML |

## 实现文件

| 文件 | 说明 |
|------|------|
| `frontend/src/utils/noteNativeExport.ts` | 原格式转换、路径构建、重名处理 |
| `frontend/src/utils/noteBulkExport.ts` | 分页拉取、DirectoryPicker / JSZip 写入 |
| `frontend/src/components/note/NoteListPanel.tsx` | 列表头「导出全部」按钮与进度 overlay |

## 使用方式

在笔记列表侧栏标题栏点击下载图标，选择本地文件夹（Chrome/Edge 等支持时），或在浏览器不支持时自动下载 ZIP 压缩包。
